# Dicas — F04

Leia apenas a dica do checkpoint em que você está trabalhando.

## F04-A01

- DICA 1 — Cada estudante ocupa um Array interno.
- DICA 2 — A matriz externa precisa conter três linhas.
- DICA 3 — Monte três Arrays de duas notas dentro de um Array maior.

## F04-A02

- DICA 1 — Escolha primeiro a linha.
- DICA 2 — Depois escolha a coluna dentro da linha.
- DICA 3 — Pseudocódigo: matriz[linha][coluna].

## F04-A03

- DICA 1 — Uma linha é um dos Arrays internos.
- DICA 2 — Somente um índice é necessário para escolher a linha.
- DICA 3 — Devolva o Array interno na posição recebida.

## F04-A04

- DICA 1 — A coordenada usa dois índices.
- DICA 2 — Atribua a nova nota depois de selecionar linha e coluna.
- DICA 3 — Altere primeiro; devolva a mesma matriz depois.

## F04-A05

- DICA 1 — O tamanho da matriz externa informa as linhas.
- DICA 2 — O tamanho da primeira linha informa as colunas.
- DICA 3 — Devolva as duas quantidades em um Array nessa ordem.
