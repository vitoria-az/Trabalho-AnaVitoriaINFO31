# Dicas — F06

Leia apenas a dica do checkpoint em que você está trabalhando.

## F06-A01

- DICA 1 — Crie um `Map<string, number>` vazio.
- DICA 2 — Cada nome deve ser associado a uma nota com `set`.
- DICA 3 — Registre os três pares e devolva o Map.

## F06-A02

- DICA 1 — Map registra pares com um método.
- DICA 2 — A chave vem antes do valor.
- DICA 3 — Use `set(nome, nota)` e devolva a coleção.

## F06-A03

- DICA 1 — A busca é feita pela chave, não por índice.
- DICA 2 — Use o método `get`.
- DICA 3 — Passe `nome` para `get` e devolva o resultado.

## F06-A04

- DICA 1 — Map não duplica a mesma chave.
- DICA 2 — `set` também atualiza uma chave existente.
- DICA 3 — Registre novamente a mesma chave com a nova nota.

## F06-A05

- DICA 1 — Comece com um Map vazio.
- DICA 2 — Faça uma chamada `set` para cada par nome/nota.
- DICA 3 — Devolva a coleção somente depois das três associações.
