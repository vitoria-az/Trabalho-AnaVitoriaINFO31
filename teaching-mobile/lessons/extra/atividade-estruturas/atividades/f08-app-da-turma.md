# F08 — Missão final: App da Turma

> Referência conceitual: slides 49. Tempo típico: 2–8 minutos por checkpoint.

## Objetivo

Integrar Array, matriz, Set, Map e Object como estado de uma futura interface Web/Mobile.

## Arquivo de trabalho

`src/fases/f08-app-da-turma.ts`

## Desafios

### F08-A01 — Criar estado vazio (35 XP)

Crie um App da Turma vazio, com Array, matriz, Set e Map nas propriedades tipadas.

**Comportamento esperado:** o verificador deve confirmar a operação para diferentes dados quando a tarefa recebe parâmetros.

### F08-A02 — Adicionar estudante (35 XP)

Adicione o aluno ao Array e sua linha de notas à matriz; devolva o mesmo App.

**Comportamento esperado:** o verificador deve confirmar a operação para diferentes dados quando a tarefa recebe parâmetros.

### F08-A03 — Registrar tecnologia (35 XP)

Adicione a tecnologia ao Set do App e devolva o mesmo App.

**Comportamento esperado:** o verificador deve confirmar a operação para diferentes dados quando a tarefa recebe parâmetros.

### F08-A04 — Registrar média (35 XP)

Associe o nome à média em `notasPorAluno` e devolva o mesmo App.

**Comportamento esperado:** o verificador deve confirmar a operação para diferentes dados quando a tarefa recebe parâmetros.

### F08-A05 — Montar painel (35 XP)

Devolva um objeto com o aluno do índice, a nota do bimestre e sua média no Map.

**Comportamento esperado:** o verificador deve confirmar a operação para diferentes dados quando a tarefa recebe parâmetros.

