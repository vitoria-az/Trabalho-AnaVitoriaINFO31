# Laboratório — Estruturas de Dados

## Objetivo

Praticar estruturas de dados em TypeScript por meio do **App da Turma**, com feedback imediato e 1000 XP possíveis.

## Preparação

```bash
npm ci
```

## Verificar ambiente

```bash
npm run doctor
```

## Como trabalhar

1. Abra a fase indicada pelo terminal.
2. Leia o desafio em `atividades/`.
3. Altere somente o arquivo `.ts` indicado e os seus TODOs.
4. Salve.
5. Execute `npm run check`.

## Ver progresso

```bash
npm run status
```

## Pedir uma dica

```bash
npm run dica -- F02-A03
npm run dica -- F02-A03 2
```

## Conferir os tipos

```bash
npm run typecheck
```

## Regras

- Não altere `grader/`, `scripts/` ou `src/lib/`.
- Não procure respostas prontas: experimente, erre, leia a dica e execute novamente.
- Cada execução recalcula a pontuação; repetir um acerto não duplica XP.
